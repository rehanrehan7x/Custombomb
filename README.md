# ThumbGrab — YouTube Thumbnail Downloader

A clean black-and-white YouTube thumbnail downloader built with Node.js + Express.

## Run on Windows

1. Install Node.js.
2. Open Command Prompt in this folder.
3. Run:
   npm install
   npm start
4. Open: http://localhost:3000
