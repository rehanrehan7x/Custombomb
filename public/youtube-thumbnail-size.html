YouTube Thumbnail Size Guide

For standard horizontal video thumbnails, 1280×720 pixels and a 16:9 aspect ratio are widely used recommendations. The exact public download resolution can vary by video and by the thumbnail file YouTube exposes.

What is the best YouTube thumbnail size?

For a standard YouTube video, 1280×720 is the recommended thumbnail dimension. Use the highest available source image when you need the clearest result.

Which thumbnail quality should you choose?

Start with the highest available quality. If that image is unavailable for a particular video, choose the next available variant.
